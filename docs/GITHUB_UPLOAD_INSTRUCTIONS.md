# GitHub upload instructions

## Repository settings

**Repository name**

`sequence-context-methylation`

**Description**

`Reproducible WGBS analyses of local DNA sequence effects on CpG and CpH methylation across human tissues, motor neurons, and matched normal-tumor liver.`

**Visibility**

Use `Public` when ready for manuscript submission.

**Suggested topics**

`dna-methylation`, `wgbs`, `epigenomics`, `cpg`, `cph`, `dnmt`, `sequence-context`, `cancer-epigenetics`, `bioinformatics`, `python`

## What to upload

Unzip the release package on your computer. Open the folder `sequence_context_methylation_reproducibility_v1.0.0` and upload **everything inside it** to the root of the GitHub repository. Do not upload the outer ZIP as the only repository file.

The repository root should show `README.md`, `CITATION.cff`, `LICENSE`, `requirements.txt`, `scripts/`, `docs/`, `reduced_results/`, and `figures/`.

**Release notes:**
